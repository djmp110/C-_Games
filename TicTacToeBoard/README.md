# Tic-Tac-Toe

A console tic-tac-toe project with a landing menu and a 3-by-3 board. The board supports move validation, undo, draw and win detection, and available move and winning cell queries. Use the menu to start and play a game.

## Build

Run from this directory:

```sh
g++ main.cpp landing.cpp Game.cpp Board.cpp statistics.cpp -o tictactoe
```

## Run

```sh
./tictactoe
```
